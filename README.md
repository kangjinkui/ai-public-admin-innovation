# 행정을 잇는 공공개발의 달인 — 발표자료 v2

제16회 지방행정의 달인 발표용 HTML 슬라이드입니다(본편 17장 + 보너스 3장, 총 20장). 빌드 과정이 없는 정적 페이지라 `index.html`을 브라우저로 바로 열면 됩니다.

- 웹: https://ai-public-admin-innovation.vercel.app/
- PDF: [`presentation.pdf`](presentation.pdf) (하단 컨트롤의 PDF 버튼으로도 받을 수 있음)
- 이전 버전(NotebookLM 이미지 13장 뷰어): [`/legacy/`](legacy/)

## 조작

| 키 | 동작 |
|---|---|
| `←` `→` / `Space` / `PageUp` `PageDown` | 이전·다음 슬라이드 |
| `Home` / `End` | 처음 / 끝 |
| `N` | 발표자 노트 열기·닫기 |
| `O` | 전체 슬라이드 보기 |
| `F` | 전체 화면 |
| URL `#s8` | 해당 슬라이드로 바로 이동 |

인쇄(Ctrl+P → PDF로 저장)하면 1장이 1페이지로 나옵니다. "라이브로 보기" 버튼은 인쇄 시 숨겨집니다.

## 수치 관리

- 슬라이드의 모든 수치는 `data/facts.json`(사실 원장)에 출처와 함께 등록되어 있어야 합니다.
- 수치를 바꾸거나 추가하면 원장도 함께 고친 뒤 검증을 돌립니다.

```bash
node scripts/verify.js
```

검증 항목: 장수·발표자 노트, 원장에 없는 수치, 금지 표현(예: `90%`, `8회`, `판정 매칭률`, `15분 →`), 필수 문구(`사람 승인`, 집계 기준 구분 등), 개인정보·내부 경로 노출, 이미지 실존·대체텍스트, 외부 링크 허용목록.

## 렌더 검증 (선택)

Playwright가 설치된 환경에서 3개 해상도(1920×1080, 1366×768, 390×844) 캡처, 넘침·콘솔 오류 점검, PDF 쪽수 확인을 합니다.

```bash
PW_CHANNEL=msedge PLAYWRIGHT_DIR=<playwright가 설치된 node_modules> node scripts/render.js <출력폴더>
```

## 화면 자료

`assets/screens/`의 캡처는 증빙자료 화면을 잘라 쓴 것입니다. 이메일·광고 영역은 잘라냈습니다. 8장의 판정 결과 화면만 같은 입력값으로 2026-10-06에 라이브 사이트(signcheck.vercel.app)에서 다시 캡처했습니다. 19장 `dangjik-live.webp`는 ai-dangjik 당직앱의 실시간 대화 컴포넌트에 **가상 통화 데이터**를 넣어 렌더링한 화면입니다(실제 통화 아님).
