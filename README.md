# 행정을 잇는 공공개발 — AI로 잇는 공공행정 혁신

16년의 현장 경험과 AI 코딩으로 단절된 행정의 흐름을 다시 잇다.
강남구 도시계획과 강진규 · 제16회 지방행정의 달인(일반행정 분야) 발표자료를 웹에서 볼 수 있도록 만든 슬라이드 뷰어입니다.

## 구성

| 슬라이드 | 내용 |
|---|---|
| 1–3 | 문제 정의: 현장↔사무실, 법령↔담당자, 전임자↔후임자의 단절과 3대 공공개발 연결망 |
| 4–5 | 정당현수막 관리 — 위치 데이터 기반 선제적 현장관리, 기간 경과 민원 70% 감소 |
| 6–8 | 옥외광고 AdJudge — 4단계 규칙 엔진, 검토시간 15분 → 1분, 반경 200m 공간 분석 |
| 9–11 | LLM Wiki 파이프라인(질의응답 265건 지식화)과 격주 업무보고 자동 수합판 |
| 12–13 | 예산 0원·35일 자체 개발, 'AX 행정'의 청사진 |

## 사용법

- `←` `→` / 스페이스 / 스와이프로 이동, `Home` `End`로 처음·끝
- URL 해시로 특정 슬라이드 공유 (예: `/#6`)
- 원본 PDF: [`presentation.pdf`](presentation.pdf)
